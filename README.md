## المعادلات المستخدمة

### BMI

```
الوزن ÷ (الطول بالمتر × الطول بالمتر)
```

### BMR

معادلة Mifflin-St Jeor

للذكور

```
10 × الوزن
+ 6.25 × الطول
− 5 × العمر
+ 5
```

للإناث

```
10 × الوزن
+ 6.25 × الطول
− 5 × العمر
− 161
```

### TDEE

```
BMR × مستوى النشاط
```

## Calculations

### BMI

```
Weight (kg) / Height² (m)
```

### BMR

Uses the **Mifflin-St Jeor Equation**

Male

```
10 × Weight
+ 6.25 × Height
− 5 × Age
+ 5
```

Female

```
10 × Weight
+ 6.25 × Height
− 5 × Age
− 161
```

### TDEE

```
BMR × Activity Level
```
